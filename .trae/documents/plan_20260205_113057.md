这是一个添加层级侧边栏（Hierarchy Sidebar）的实施计划。

我们将创建一个位于画布左侧的新侧边栏，作为项目的顶级导航，支持在“魔法画布”和“图像生成”等模块间切换，并支持展开/收起。

### 1. 状态管理更新 (useUIStore)
我们需要在 `useUIStore.ts` 中添加管理新侧边栏状态的逻辑：
- `projectSidebarOpen`: 控制侧边栏展开/收起（默认 `true`）。
- `activeModule`: 当前激活的模块（默认 `'magic-canvas'`）。
- `toggleProjectSidebar`: 切换展开/收起状态的 Action。
- `setActiveModule`: 切换模块的 Action。

### 2. 创建 ProjectSidebar 组件
在 `src/components/layout/ProjectSidebar.tsx` 创建新组件：
- **布局**: 固定在左侧，高度 100vh，背景色为白色（亮色模式）或深色（暗色模式，匹配当前设计）。
- **头部**: 包含 Logo ("Design Work") 和收起按钮。
- **导航项**:
  - **魔法画布** (Magic Canvas) - 对应 `1.1.1`
  - **图像生成** (Image Gen) - 对应 `1.2.1`
  - 视频生成 (Video Gen)
  - 对话助手 (Chat Assistant)
  - ...以及底部导航项（创意灵感、实用工具等）。
- **交互**: 点击导航项切换 `activeModule`，点击收起按钮切换 `projectSidebarOpen`。

### 3. 调整 AppShell 布局
修改 `src/components/layout/AppShell.tsx`：
- 引入 `ProjectSidebar`。
- 使用 Flex 布局将 `ProjectSidebar` 放置在最左侧。
- 原有的 `main` (Canvas) 和悬浮 UI (`Header`, `Sidebar` 等) 将被包裹在一个容器中，位于 `ProjectSidebar` 右侧。
- 根据 `projectSidebarOpen` 状态动态调整右侧容器的宽度（`flex-1`）。

### 4. 调整 Header 组件
修改 `src/components/layout/Header.tsx`：
- 当侧边栏收起时，Header 左侧可能需要显示一个“展开侧边栏”的按钮（或者复用现有的 Header 逻辑，确保它不会被遮挡）。
- 根据用户描述，Header 似乎是悬浮在 Canvas 上的，所以位置可能需要微调，或者保持 `fixed` 但 `left` 值根据侧边栏宽度动态计算。
- **更优方案**: 将 Header 的 `left` 属性改为依赖侧边栏状态，或者将其放入右侧内容区域的流式布局中而非 `fixed` 全局。考虑到现有代码是 `fixed top-4 left-4`，我们可能需要将其改为 `absolute` 或调整 `left` 偏移量。

### 5. 模块切换逻辑
- 当切换到“图像生成”时，虽然目前没有具体的图像生成页面代码，我们将创建一个占位组件或简单的视图切换逻辑，以便演示导航功能。

### 6. 样式与图标
- 使用 `lucide-react` 图标库匹配 Figma 设计中的图标。
- 样式将使用 Tailwind CSS，参考 Figma 导出的 CSS 模块进行转换。

3.  修改 `AppShell.tsx` 集成侧边栏。
4.  微调 `Header.tsx` 和其他悬浮组件的位置逻辑。
