# 导航栏位置设置设计

## 目标

在个性化设置的“导航栏设置”中增加“导航栏位置”单选项，支持左侧、顶部、右侧。选择后立即改变主导航的实际布局，并持久保存。

## 交互规则

- 三个位置共用同一组导航项、选中状态和模块切换逻辑。
- 左侧保持现有布局。
- 右侧为左侧布局的方向镜像，展开、收起与完全隐藏行为不变，展开按钮位于导航栏左边缘。
- 顶部导航横向排列：展开时显示图标和文字，收起时只保留图标，“完全隐藏”时整条导航高度为零。
- 内嵌、普通、浮动三种导航样式继续有效；边距、边界、圆角和阴影按导航方向适配。
- 导航不使用覆盖式定位，主内容在三种位置下都会自动占据剩余空间。

## 状态与迁移

- 新增 `NavigationPosition = 'left' | 'top' | 'right'`。
- 新增持久化字段 `navigationPosition`，默认值为 `left`。
- 旧版持久化状态缺少该字段时迁移为 `left`；非法值同样回退到 `left`。
- “恢复默认”将导航位置恢复为左侧。

## 组件设计

- `GeneralSettings` 在导航栏样式之前增加三段式“导航栏位置”控件。
- `AppShell` 根据位置切换容器主轴方向和导航/工作区顺序。
- `ProjectSidebar` 保持单一组件，根据位置切换宽高、主轴、导航项展示、分隔边和展开按钮位置。
- 根容器暴露 `data-navigation-position`，供主题 CSS 做方向相关的表面适配。

## 验证

- 状态测试覆盖默认值、三种位置切换、持久化迁移与恢复默认。
- 布局验证覆盖左侧、右侧、顶部的展开、保留图标和完全隐藏状态。
- 运行客户端类型检查、Lint、项目测试与 diff 检查。

## 非目标

- 不改变导航信息架构、顺序或模块路由。
- 不新增第二套顶部导航组件。
- 不改动内容模块内部的二级侧栏。
