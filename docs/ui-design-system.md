# Mboard UI 组件规范

> 这份规范是所有工作区模块的默认视觉与交互合同。新增或改造页面优先复用现有 token、基础组件和状态，不为单个页面另造一套尺寸、颜色或圆角。只记录当前规则，不追加任务历史。

## 1. 视觉方向

Mboard 采用克制的中性工作台风格：亮色使用黑、白和浅灰，暗色使用黑与中性深灰。层级主要依靠留白、圆角和轻微表面差异表达，不用彩色渐变、高对比描边或大面积品牌色。语义色只用于成功、警告、错误等明确反馈；现有荧光色实现视为待迁移遗留，不在新界面中扩散。

## 2. 设计 token

### 色彩

| 用途 | Light | Dark | 说明 |
| --- | --- | --- | --- |
| 工作区背景 | `#fff` | `#0b0b0b` | 页面最底层 |
| 次级表面 | `#f8f8f6` | `rgba(255,255,255,.035)` | 灰色内容块、工具栏底 |
| 控件底色 | `#f3f3f1` | `rgba(255,255,255,.06)` | 无描边输入框、下拉控件 |
| hover 表面 | `#e8e8e6` | `#1d1d1d` | 非选中控件 hover |
| 选中表面 | `#111111` | `#f5f5f5` | 当前导航、分段控件与可确认选中 |
| 选中前景 | `#ffffff` | `#111111` | 选中表面上的文字与图标 |
| 主文本 | `#111713` | `#f5f5f5` | 标题和主要操作 |
| 次文本 | `#59635c` | `#a3a3a3` | 辅助信息 |
| 弱文本 | `#8a948d` | `#6f6f6f` | 数字、说明、元数据 |
| 分割线 | `rgba(19,28,22,.06)` | `rgba(255,255,255,.07)` | 仅在必要层级使用 |

### 尺寸与间距

- 基础间距单位为 4px；只使用 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px 的间距阶梯，常用节奏为 8 / 12 / 16 / 24px。
- 顶部操作栏与主内容块的垂直间距为 16px；状态栏与内容块不额外添加空白。
- 页面外侧大边距为 64px；内容块自身内边距为 8px。
- 左右栏之间使用 12px；内容卡片/瀑布流列之间使用 24px。
- 标准输入框、按钮、下拉框和 tabs 外框高度均为 32px；紧凑图标按钮的可见尺寸可为 28px，但点击热区不得小于 32px。
- tabs 选中项为 28px 高，外框以 2px 内边距包住选中项。
- 控件圆角为 8px；卡片和面板统一使用 `var(--radius)`（默认 10px）；弹窗可使用 12px。禁止同一模块混用 16/18/20/22px 等装饰性圆角。
- 素材库顶部操作栏为 56px 高；标签列表项为 32px 高；图片卡片圆角为 10px。

### 字体

- 中文正文和控件优先使用 `PingFang SC`（苹方），回退到系统无衬线字体；正文 14px，辅助文字 12px，元数据 10–11px。
- 一级模块标题：16–20px、600；页面内标题避免超过两个视觉层级。
- 数字列使用 `tabular-nums`，并设置固定宽度和右对齐，保证标签、统计卡和表格稳定对齐。

## 3. 组件合同

### 页面壳层

页面使用 `module-workspace` 作为根容器，背景为 `var(--workspace-bg)`，不添加外层边框。工作台内部优先使用：

```text
module-workspace
  ├─ module-toolbar（32/40px 高，左右对齐）
  └─ module-surface（浅灰或白色内容表面）
```

模块之间用 gap 表达关系，不用贯穿式竖线；只有当用户需要明确分组或拖拽边界时才使用浅色分割线。

### 操作栏

- 左侧放模块切换、标题或返回；右侧放筛选、排序、导入、导出等动作。
- 主操作使用中性深色实心按钮（暗色模式反转为浅色）；次操作使用无描边灰底或 ghost 按钮。
- 搜索框默认 32px 高、灰底、无描边；宽度根据模块密度控制在 320–420px。
- 搜索框在顶部操作栏中靠右对齐，右侧不再保留无意义的占位间距。
- 图标按钮必须有 `aria-label` 和 `title`，点击热区不小于 32px。

### 导航与标签

- 选中背景允许向左右外扩 12px，但文字、数字、操作按钮仍保持同一内容对齐线。
- 选中项使用高对比中性色底表达当前上下文；不要再叠加描边或分割线。暗色模式下前景与背景同步反转。
- hover 只使用比默认背景高一个层级的浅灰/深灰，不能与 selected 同强度，也不改变控件尺寸。
- focus-visible 使用清晰的 2px 中性焦点环；hover、selected 和 focus 必须是互不混淆的状态。
- 标签名称 14px；数字固定宽度、右对齐；编辑/删除操作放在数字左侧，并只在 hover/focus 时显现。

### 面板与卡片

- 输入、选择器、工具栏和面板优先使用灰底无描边；通过 `bg-[#f8f8f6]`、`bg-card` 和 8/12px 留白区分层级。
- 需要边界时使用 1px、低透明度边框，不使用深色描边或强阴影。
- 卡片 hover 只改变背景和轻微阴影，不改变布局尺寸。

### 反馈与交互

- 所有异步操作显示进行中状态；完成后显示短暂 notice，失败保留可读错误。
- 拖拽区域在 drag-over 时提升背景和边框对比度，但不改变尺寸。
- 空状态必须说明当前上下文、原因和下一步动作。
- 所有状态（选中、hover、focus、disabled、loading）都要有键盘可感知的等价表现。

### 暗黑模式

- 暗黑模式只替换语义 token，不在组件中散落另一套硬编码颜色。
- 深色表面按 `#0b0b0b` → `rgba(255,255,255,.035)` → `rgba(255,255,255,.06)` 递进；避免纯白描边和强阴影。
- 主文字、次文字、弱文字保持清晰层级；disabled 仍需可辨认，不能只靠降低透明度到不可读。
- selected 使用浅色表面与深色前景，hover 使用较弱深灰；语义色在深色背景上必须检查对比度。

## 4. 模块落地规则

- 素材库：左筛选栏 200px，栏与主内容 gap 12px，瀑布流 gap 24px；导入入口位于内容标题栏右侧；标签选中背景向两侧外扩 12px，新增标签按钮与选中边界对齐。
- 图片/视频/PPT 生成：控制栏与预览栏使用同一 `module-surface` 语言，控制栏宽度固定、预览区自适应。
- 无限画布：画布保持无边界；悬浮工具栏使用 32px 控件和轻灰表面，不加贯穿式结构线。
- 设置、弹窗、抽屉：沿用 10px 圆角、8px 内层留白、12px 控件间距，标题与操作对齐同一基线。

## 5. 验收清单

- [ ] 32px 控件高度一致，tabs 选中项为 28px + 2px 内边距，图标点击热区不小于 32px。
- [ ] 页面外侧、面板内侧、栏间距分别遵守 64 / 8 / 12 / 24px。
- [ ] 搜索与输入控件无不必要描边，使用灰底和 focus ring。
- [ ] hover / selected / focus 层级清楚，背景有留白，不贴底、不挤压文字和数字。
- [ ] 数字列右对齐，操作图标位于数字左侧。
- [ ] Light/Dark 两套 token 均可读，暗色保持中性。
- [ ] 键盘 focus、aria-label、loading、错误和空状态齐全。
