# 任务：合并素材入口并调整素材分类

- 状态：#已完成
- 负责人：Codex
- 优先级：P1
- 创建日期：2026-08-07
- 截止日期：2026-08-07

## 目标

将图片、视频两个独立入口合并为“素材”，并在素材页面内使用图片、视频、项目三类标签切换。

## 范围

- 侧栏导航：图片、视频 → 素材。
- 素材页面顶部 tabs：图片、视频、项目。
- 视频 tab 复用现有视频素材目录与导入能力。

## 不在范围内

- 不改变图片资产的筛选、导入与详情逻辑。
- 不改变视频生成工作台和项目详情逻辑。

## 验收标准

- [x] 侧栏只显示一个“素材”入口。
- [x] 素材页面显示“图片 / 视频 / 项目”三类 tabs。
- [x] 点击视频 tab 可显示视频资产目录，不出现空白页面。
- [x] 点击项目 tab 显示原视频模块的工程列表、预览详情和创建工程入口。
- [x] 项目列表顶部增加标题，并支持“视觉设计 / 视频工程”下拉切换。
- [x] 项目模块左右标题栏统一为 44px，右侧支持收起和展开项目列表。
- [x] 客户端类型检查通过。

## 记录

- 修改 ProjectSidebar.tsx、AssetLibraryPage.tsx、VideoGeneration.tsx。
- 视频 tab 直接复用 VideoAssetCatalog；项目 tab 直接复用 VideoProjectLibrary，避免重复实现筛选、排序、导入和工程详情。
- 项目类型切换沿用同一工程详情布局，仅替换项目数据源。
- 项目模块对齐图片模块的双栏标题结构，收起项目列表后详情区自动占满。
