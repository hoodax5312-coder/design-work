# 任务：文档树新建与拖拽

- 状态：#已完成
- 负责人：Codex
- 优先级：P1
- 创建日期：2026-08-04
- 截止日期：2026-08-04

## 目标

参考 Obsidian 文件浏览器，优化文档左侧树结构并增加新建和拖拽归档能力。

## 范围

- 文件夹节点去掉文件夹图标，仅保留展开箭头和层级缩进。
- 笔记节点保留文件图标，与文件夹形成区分。
- 增加独立的“新建笔记”和“新建文件夹”操作。
- 新建条目立即进入命名状态。
- 支持树节点拖入文件夹，文件夹显示接收反馈。
- 支持拖回根目录。
- 本地持久化文档树和项目文件的目录归属。

## 不在范围内

- 不实现同级精确排序和拖拽插入线。
- 不实现文件删除、批量移动和跨设备同步。
- 不修改右侧多文件标签和内容展示。

## 验收标准

- [x] 文件夹节点不显示文件夹图标。
- [x] 新建笔记与新建文件夹操作可明确区分。
- [x] 新建条目进入命名输入状态。
- [x] 树节点具备原生 draggable 属性，文件夹和根目录具备 drop 处理。
- [x] 拖拽后的目录归属写入本地存储。
- [x] 客户端类型检查和 lint 通过。

## 记录

- 浏览器自动化对原生 HTML5 drag/drop 合成事件不稳定；实现已通过 DOM 能力检查和代码验证。
