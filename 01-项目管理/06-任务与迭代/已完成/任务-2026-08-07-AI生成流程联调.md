- 状态：#已完成
- 负责人：Codex
- 优先级：P1
- 创建日期：2026-08-07

## 目标

使用已配置的智汇云模型，跑通真实图像和视频生成，并将结果回收到素材库。

## 范围

- Provider Base URL 归一化与智汇云鉴权兼容。
- 图像生成 `/v1/images/generations`。
- 视频生成 `/v1/video/generations`。
- 视频真实结果在素材 → 视频中预览。

## 验收标准

- [x] 真实配置生成图片并显示生成记录。
- [x] 视频请求使用智汇云要求的 `api-key` 兼容鉴权头。
- [x] 视频使用 `resolution`、`response_format: b64_json` 和 Wan2.1 支持的分辨率。
- [x] 长时视频请求不会在默认 5 分钟超时。
- [x] 真实供应商返回 MP4，素材 → 视频能渲染 `<video>` 预览。
- [x] 不将大体积 base64 视频写入 localStorage，避免配额错误。

## 记录

- 智汇云控制台确认视频接口为 `https://llm.api.zyuncs.com/v1/video/generations`。
- 真实测试提示词：白色陶瓷杯在木桌上，镜头缓慢推进。
- 真实结果返回可播放的签名 MP4 URL；前端素材视频列表显示 1 条视频并渲染视频元素。
- 相关验证：`npm run typecheck`、`npm run lint`、`npm test`，43 项测试全部通过。
