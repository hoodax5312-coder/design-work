# 任务：统一输入控件焦点状态

- 状态：#已完成
- 负责人：Codex
- 优先级：P1
- 创建日期：2026-08-04
- 截止日期：2026-08-04

## 目标

消除输入控件激活时由 2px ring offset 产生的额外外部间距与描边，确保激活前后控件视觉尺寸一致。

## 范围

- 统一基础 Input、Textarea、Select 的焦点样式。
- 检查项目内可见输入控件和原生输入元素。
- 修正组合输入卡的 focus-within ring 为内部绘制。
- 将焦点尺寸规则补充进 UI 设计规范。

## 不在范围内

- 不修改按钮、Tabs、开关和复选框的焦点样式。
- 不改变输入控件默认高度、宽度、颜色和交互逻辑。

## 验收标准

- [x] 输入框、文本域和下拉框不再使用 ring offset。
- [x] 焦点环绘制在控件内部。
- [x] 激活前后控件 bounding box 完全一致。
- [x] 客户端类型检查通过。

## 记录

- 搜索框实测激活前后均为 168 × 32px，ring offset 为 0px。
- 小记文本域实测激活前后均为 258 × 290px。
- 项目内直接使用的原生 input 均为隐藏文件选择器，无额外可见文本输入样式。
