## 目标

优化创作画布中的图片与视频节点，将提示词、模型和生成操作集中到选中后显示的统一输入框中。

## 范围

- 03-程序区/前端代码/components/nodes/ImageGenNode.tsx
- 03-程序区/前端代码/components/nodes/VideoNode.tsx

## 不在范围内

- 文本节点、音频节点及画布连线逻辑。
- 节点数据结构和生成服务接口。

## 验收标准

- [x] 未选中时图片/视频节点只展示媒体卡片信息。
- [x] 点击选中图片或视频节点后显示统一输入框。
- [x] 输入框包含提示词、模型选择和生成操作。
- [x] 输入框属于节点内容，拖动节点时跟随移动。
- [x] 通过 npm run typecheck:client。

## 记录

- 图片节点保留比例与质量设置，并收纳到选中后的输入面板。
- 视频节点将模型、Provider、任务状态与错误提示收纳到选中后的输入面板。
- 使用 nodrag/nowheel，保证输入控件操作不会触发画布拖动或滚动。
