# 任务：画布节点入口与输入收敛

- 状态：#已完成

- 截止日期：2026-08-06

## 目标

简化创作画布中的节点类型和操作入口，减少生成模式分支，让节点以图片、视频、文本三类核心对象呈现。

## 范围

- 图片节点与视频节点的标题、提示词文案和创建入口。
- 文本节点的编辑/生成输入框。
- 画布侧栏组件列表的搜索与类型筛选区域。

## 不在范围内

- 生成服务接口、模型配置数据结构和连线逻辑。
- 画布之外的素材库搜索或筛选。

## 验收标准

- [x] 图片节点不再区分文生图、图生图，统一显示“图片”。
- [x] 视频节点不再区分文生视频、图生视频，统一显示“视频”。
- [x] 工具栏图片和视频各保留单一节点入口。
- [x] 文本节点只保留一个输入框，并保留模型选择与生成操作。
- [x] 画布侧栏移除搜索框和类型筛选按钮。
- [x] 通过 npm run typecheck:client。

## 记录

- 节点创建默认数据不再写入 generationMode。
- 媒体节点继续保留提示词、模型与生成操作，但统一在选中后的输入面板中呈现。
- 侧栏仍保留画布列表和组件定位列表，移除与当前需求无关的搜索和筛选控件。
