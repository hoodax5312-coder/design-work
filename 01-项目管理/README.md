# 项目管理库（Obsidian 风格）

这是 Mboard 项目的项目管理骨架，不是自动归档区。当前只建立目录、入口和模板，不自动写入产品文档、截图、聊天记录或历史结论。

如果你是项目负责人或非技术人员，请先打开项目根目录的 `00-老板入口/先看这里.md`，再回到本目录管理任务和资料。

## 使用方式

1. 从 `项目总览.md` 开始。
2. 新资料先放进 `待确认资料.md`，不要直接归档。
3. 只有用户明确同意后，才把资料复制或整理到正式目录。
4. 每个任务、决策、会议、风险和复盘使用对应模板建立独立笔记。

## 目录地图

```text
项目管理/
├── 项目总览.md、工作台.md、待确认资料.md
├── 01-产品战略/（愿景、用户、边界）
├── 02-资产与知识平台/（核心产品能力）
├── 03-创作工作流/（图像、视频、PPT、画布）
├── 04-体验与设计/（信息架构、UI、主题、UX）
├── 05-工程与交付/（架构、数据、测试、版本、发布）
├── 06-任务与迭代/（任务、路线图、版本）
├── 07-决策与风险/（决策、评审、风险、问题）
├── 08-资料与证据/（经确认纳入的资料）
├── 09-复盘与交接/（复盘、状态、交接）
├── 归档/
└── _模板/
```

## 约定

- 根目录只放项目总览、工作台、待确认资料三个高频入口。
- `01-产品战略` 记录相对稳定的项目事实。
- `02-资产与知识平台` 管理 Mboard 的核心资产库和知识库能力。
- `03-创作工作流` 管理生成、画布、视频、PPT 和资产回流。
- `04-体验与设计` 管理产品体验与视觉系统。
- `05-工程与交付` 管理实现、验证、发布和交接。
- `06-任务与迭代` 管理可执行工作及其状态。
- `07-决策与风险` 管理讨论结论、决策、风险、问题和变更。
- `08-资料与证据` 只登记来源和用途；正式纳入前先确认。
- `09-复盘与交接` 记录事实、原因、改进和交接行动。
- `归档` 只放已完成或失效内容，不删除历史。

状态标签：`#待确认` `#待开始` `#进行中` `#阻塞` `#已完成` `#已归档`
